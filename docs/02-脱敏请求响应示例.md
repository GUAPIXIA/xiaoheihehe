# 交付物 2 — 关键只读接口的脱敏请求与响应示例

## 说明

- 所有示例均来自 **本次真实只读请求**（详见 `evidence/report2.md` – `report8.md`），**保留真实字段名与真实结构**。
- 脱敏规则：个人身份（`userid`/`username`/`avatar`/`signature`/`ip_location`）→ `<已脱敏>`；正文文本（`title`/`description`/`text`）→ `<文本已省略>`；媒体 URL → 仅保留 `scheme://host/<path>`；干扰性 UI 结构（`feedback`/`bottom_rich_text` 等）→ `<结构已省略>`；**结构数值与枚举（`topic_id`、社区名、`content_type`、`link_tag`、`lastval`、`expire`）保留真实值**。
- **全部示例不含任何真实 Cookie、pkey、token 或账号凭据**。本次调研全程匿名，未登录、未提交任何写入操作。
- `hkey` / `nonce` 在示例中以占位符表示（它们是一次性签名，本身也属敏感物）。算法与公共参数见 `01-接口表.md` 第 0 节。
- `device_id` 为本次随机生成的本地值，**不是任何真实用户的设备指纹**。
