## ⚡ 30 秒结论

1. **匿名即可读**：综合流、社区列表、社区头条、社区目录、社区详情、搜索、用户主页、关注/粉丝、Emoji、登录二维码 —— 全部实测通过。
2. **帖子详情 `/bbs/app/link/tree` 需要登录**（匿名返回 `status:"show_captcha"`），这是**当前唯一的主线阻塞点**，也是评论/楼中楼无法验证的原因。
3. **社区过滤没有任何服务端支持**：
   - 不支持一次多个社区（重复 `topic_id` 只取第一个）；
   - **不存在**"排除分区"参数（网页 JS 里 `exclude_topic` / `屏蔽` / `block_topic` **0 命中**）；
   - 综合流带 `topic_id` 只是**软加权**（3/11 命中），不是过滤。
   → **"只看"靠逐社区拉取 + 本地归并，"屏蔽"只能本地过滤。**
4. **关键更正**：`link_tag` **不是社区分区**，而是内容形态（`1=视频贴 / 11=文章 / 27=图文 / 28=新动态分区`，来自网页 JS 枚举）；真实社区归属是 `topics[].topic_id`（一篇帖子可有多个）。上游 `post.rs` 的注释是**错的**。
5. **好消息**：`/bbs/app/topic/feeds/news` 是全流程中**唯一被证实「确定性 + `lastval` 游标可靠」**的社区帖子列表（两次请求 19/19 完全一致且顺序一致），可以直接作为"只看这些社区"的**主数据源**；而 `/bbs/app/feeds` 与 `/bbs/app/topic/feeds` 都是**非确定性**的（相同请求交集为 0）。
6. **许可证**：`xhh-workshop` 是 **GPL-3.0-only**。**建议只借鉴接口契约与算法、自行重写，不要直接依赖 `xhh-core`**，否则客户端整体需以 GPL-3.0 分发。
